FileForge pour Windows
======================

INSTALLATION : double-clique sur FileForge-Setup.exe, puis Suivant et Installer.
(Si Windows affiche « Windows a protégé votre ordinateur » : Informations
complémentaires, puis Exécuter quand même.)

Installation avancée sans le .exe : powershell -ExecutionPolicy Bypass -File install.ps1

UTILISATION
- Clic droit sur des fichiers > FileForge...  (Windows 11 : Afficher d'autres options)
- Clic droit > Envoyer vers > FileForge
- Ctrl + Alt + F dans l'Explorateur
- Glisser des fichiers sur l'icône FileForge du Bureau

DÉSINSTALLER : Paramètres > Applications > FileForge > Désinstaller.
Journal : %LOCALAPPDATA%\FileForge\FileForge.log
